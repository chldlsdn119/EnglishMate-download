## 설치 방법
1. 위 링크로 APK 파일을 받습니다.
2. 다운로드 알림이나 '내 파일' 앱에서 APK를 누릅니다.
3. "출처를 알 수 없는 앱" 경고가 나오면 **설정 → 이 출처 허용**을 켜고 설치합니다. (Play 스토어 앱이 아니라서 나오는 경고예요)

필요한 것: 안드로이드 8.0 이상, 인터넷 연결, Google Gemini API 키(무료)

## 처음 설정 — Gemini 무료 키 받기
1. 브라우저에서 [aistudio.google.com/apikey](https://aistudio.google.com/apikey) 에 들어갑니다.
2. 구글 계정으로 로그인하고 **Create API key**를 누릅니다.
3. 만들어진 키를 복사해서 앱의 **설정** 탭 → "API 키"에 붙여넣고 **저장하고 연결 확인**을 누릅니다.

- 키는 비밀번호처럼 다루세요. 다른 사람과 공유하지 마세요.
- 결제 정보를 연결하지 않은 Gemini 키는 사용량 한도 안에서 무료예요. 한도에 걸리면 잠시 후(또는 다음 날) 다시 쓰면 됩니다.
- Claude(유료)를 쓰고 싶으면 설정에서 AI 선택을 Claude로 바꾸고 본인 Claude API 키를 넣으세요.

## 주요 기능
- 실시간 음성 통화 / 글자 대화 (상황 8개 + 나만의 상황, 난이도 3단계)
- 대화 후 문장별 교정, 문법 설명, 학습 포인트, AI 선생님에게 질문
- 표현장 + 복습 퀴즈(간격 반복), 따라 말하기
- 오늘의 미션, 학습 기록, 레벨업 권유, 학습 알림
- 백업·복원 (설정 탭)
- 갤럭시 폴드처럼 큰 화면에서는 2단, 일반 폰에서는 1단으로 자동 배치

## 개인정보 안내
- 표현장, 학습 기록, 설정, API 키는 모두 **본인 폰에만** 저장됩니다. 앱 만든 사람에게 전송되지 않아요.
- 대화 내용은 답변과 분석을 위해 본인이 고른 AI 회사(Google 또는 Anthropic) 서버로 전송됩니다.
- Google 무료 등급은 전송된 내용이 Google 서비스 개선에 쓰일 수 있어요. 민감한 개인정보는 대화에서 말하지 마세요.
- 각 AI 서비스의 이용약관(나이 제한 포함)을 확인하고 써주세요.
